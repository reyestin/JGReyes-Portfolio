# JG Reyes - Personal Portfolio

A modern, responsive portfolio website built using Astro, Preact, Tailwind CSS, TypeScript, and GSAP animations.

## 🚀 Tech Stack

* **Framework:** [Astro](https://astro.build/)
* **UI Components:** [Preact](https://preactjs.com/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Language:** TypeScript
* **Animations:** GSAP (GreenSock)
* **Deployment:** Netlify
